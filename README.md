# たべたい帖

二人家族で使う、食事のリクエストをためていくアプリです。
GitHub Pages(画面)と Firebase(データの共有)で動きます。iPhoneのホーム画面に追加して使います。

---

## 1. Firebaseの準備(最初に1回)

「ひみつのギフト」「おうちめぐり」と同じ手順です。料金プランは無料の **Spark** のままで使えます。

1. [Firebaseコンソール](https://console.firebase.google.com/)で、新しいプロジェクトを作ります(名前は例として `tabetaicho`)。Googleアナリティクスはなしで構いません。
2. 左のメニューの「構築」→「Authentication」→「始める」→「ログイン方法」で、**匿名** を有効にします。
3. 「構築」→「Firestore Database」→「データベースを作成」。場所は `asia-northeast1`(東京)を選び、「本番環境モード」で作ります。
4. Firestoreの「ルール」タブを開き、このフォルダの `firestore.rules` の中身を貼り付けて「公開」します。
5. 「プロジェクトの設定」(歯車)→「マイアプリ」→ ウェブ(`</>`)のアイコンでアプリを登録します。Firebase Hostingの設定は不要です。
6. 表示された `firebaseConfig` の6つの値を、`js/config.js` の「ここに貼り付け」の部分に貼り付けます。

> `js/config.js` の値は公開されても問題のない種類の値です。データの保護は、手順4のルールと手順2の匿名ログインで行います。

## 2. GitHub Pagesで公開

1. GitHubで新しいリポジトリを作ります(例:`tabetaicho`)。
2. このフォルダの中身をすべてアップロードします。`index.html` がリポジトリの一番上に来るようにしてください。
3. リポジトリの「Settings」→「Pages」で、Branch を `main`、フォルダを `/(root)` にして保存します。
4. 数分後、`https://(ユーザー名).github.io/tabetaicho/` で開けるようになります。
5. Firebaseコンソールの「Authentication」→「設定」→「承認済みドメイン」に `(ユーザー名).github.io` を追加します。

## 3. iPhoneに入れる

1. iPhoneの **Safari** で公開したURLを開きます。
2. 共有ボタン →「ホーム画面に追加」。
3. ホーム画面のアイコン(藍に朱の箸)から開きます。
4. 最初の画面で、二人で決めた **家族の合言葉**(8文字以上)と、「作る人」「頼む人」のどちらかを選びます。
   - 先に始める人(どちらでも可):地域・給料日・誕生日を入れて「はじめる」
   - もう一人:同じ合言葉を入れるだけで、同じ帖につながります

## 4. 使い方

| 画面 | できること |
|---|---|
| 今日 | 今日の天気・曜日・気分に合うページを3枚まで表示。ページを押すと詳しく見られます。下の「今日の気分」はどちらの端末からでも押せます |
| 書く | 食べたい/作りたい、食べたいもの(家の料理でも外食でも)、どんな日に、ひとこと・写真・リンク。二人で合計15枚まで |
| ページの詳細 | 作る人:「食べた」「今週たべる(しおり)」。二人とも:書き直す・取り下げる |
| 済んだページ | 食べたものの記録。「また食べたい」で帖に戻せます(記録はそのまま残ります) |
| 設定 | 寒い日・暑い日の気温の基準 |

### 判定のきまり

- 寒い日:最高気温が基準以下(最初は12℃)
- 暑い日:最高気温が基準以上(最初は28℃)
- 雨の日:降水確率50%以上(固定)
- 週末:土曜・日曜
- 給料日:毎月の指定日(31日など、その月にない日は月末)
- 誕生日:登録した日
- 疲れた日・元気を出したい日:その日に「今日の気分」で押したとき
- 今日の画面の並び順:しおり付き → 条件に合うもの → いつでも。同じなら書いた日が古い順

## 5. 更新するとき

ファイルを直してアップロードしたら、`sw.js` の1行目近くにある `VERSION` の数字を上げてください(例:`tabetaicho-v2`)。上げないと、iPhoneに古い画面が残ることがあります。

## ファイルの構成

```
index.html            画面の入れ物
css/style.css         見た目
js/app.js             画面と操作
js/logic.js           条件の判定(画面に依存しない部分)
js/data.js            Firebaseとのやりとり
js/weather.js         天気(Open-Meteo)と地域の検索
js/config.js          Firebaseの設定値 ← 貼り付ける
sw.js                 オフラインでも開くための仕組み
manifest.webmanifest  ホーム画面に追加したときの名前・アイコン
icons/                アイコン(180/192/512px)
firestore.rules       Firestoreのルール ← Firebaseに貼り付ける
```

天気は [Open-Meteo](https://open-meteo.com/) の無料APIを使っています(登録不要、非商用の利用)。
